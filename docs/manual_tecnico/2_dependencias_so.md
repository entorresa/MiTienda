### 2. Dependencias del sistema operativo
---

Se precisan algunas librerías a nivel de sistema operativo, mismas que se pueden instalar con el comando:

```sh
apt install libpango-1.0-0 libpangoft2-1.0-0 libcairo2 libcairo2-dev libffi-dev libjpeg-dev libopenjp2-7-dev libxml2 libxml2-dev libxslt1-dev shared-mime-info fonts-dejavu-core
```
