-   Para ver la bitácora de ventas ingrese al menú de `MiTienda.pe -> Bitácora -> Ventas`.

![](/docs/assets/bitacora_ventas/1_bitacora_ventas.png)

### 1. Listado bitácora de sincronización de ventas.

-   El listado muestra todos las ventas que se lograrón sincronizar con éxito marcadas con color verde y también se muestra las ventas que no lograrón sincronizar  por algun error, se marcan de color rojo.

-   Para mas detalles Puede ingresar al formulario haciendo click sobre cualquier registro del listado.

![listado de bitacora](/docs/assets/bitacora_ventas/2_listado_bitacora_ventas.png)
