### 4. Bitácora de sincronización de clientes
---

### Procedimiento

-   Para ver la bitácora de clientes ingrese al menú de `MiTienda.pe -> Bitácora -> Clientes`.

![menu](/docs/assets/bitacora_clientes/1_bitacora_clientes.png)

-   En el listado muestran todos los registros de clientes obtenidos desde la API y almacenados en Odoo.
-   Para mas detalles puede ingresar al formulario haciendo click sobre cualquier registro del listado.

![listado](/docs/assets/bitacora_clientes/2_listado_bitacora_clientes.png)

-   El formulario muestra los siguientes campos:
    -   __Fecha de sincronizacón:__ Es la fecha y hora en el que se realizó la sincronizacion.
    -   __Cliente:__ Es el contacto creado durante el proceso de sincronizacón.
    -   __Nombres:__ Es el nombre del cliente que se obtiene de la API.
    -   __Apellidos:__ Es el apellido del cliente que se obtiene de la API.
    -   __Botón inteligente ventas:__ Este botón nos direcciona al lista de bitacoras de sincronización de ventas

![fomulario](/docs/assets/bitacora_clientes/3_bitacora_cliente.png)
