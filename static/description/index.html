Módulo de sincronización de datos de MiTienda.pe para Odoo

Módulo para sincronizar clientes, ventas y stock de productos de inventario entre Odoo y MiTienda.pe

Para descargar datos de clientes y ventas, así como actualizar stock de inventario debe obtener un token de acceso API de MiTienda.pe y configurarlo en el módulo.
